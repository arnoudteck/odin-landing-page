# odin-landing-page
A landing page coded from scratch  as part of The Odin Project

In this project I will receive an image and some instructions on colors and fonts. With this briefing I will write all the HTML and CSS from scratch to turn the design into a real website.

After completing this project I will have proven to myself that I have a solid understanding of the foundations of HTML and CSS. I will be able to structure an HTML-DOM, style it with CSS and use flexbox to position the elements on the page. This website will not be responsive. I will learn about responsive webdesign later on in THe Odin Project.
